# Welcome to Library Manager

We're excited to introduce **Library Manager** — a modern, cross-platform library management application built with
Python and Flet!

<!-- more -->

## What is Library Manager?

Library Manager is a complete solution for managing book libraries, whether you're running a small community library, a
school library, or managing your personal book collection. Built with [Flet](https://flet.dev) (a Flutter-based Python
framework) and [SQLAlchemy](https://www.sqlalchemy.org/), it offers a beautiful, responsive UI that works seamlessly
across desktop, web, and mobile platforms.

## Key Features

### 📚 **Comprehensive Book Management**

- Add, edit, and search books with ease
- Track book details including ISBN, author, publisher, and publication year
- Assign books to physical storage locations
- Categorize books by type (Fiction, Non-Fiction, Reference, etc.)

### 👥 **Client Management**

- Register library members with contact information
- Track rental history per client
- View client activity and statistics

### 📅 **Smart Rental System**

- Rent and return books with automatic due-date tracking
- Visual indicators for overdue rentals
- Rental history and reporting
- Configurable rental periods

### 🏢 **Storage Location Tracking**

- Organize books across multiple physical locations
- Track capacity and current occupancy
- Easy book location lookup

### 🔐 **User Authentication & Authorization**

- Secure login system
- Role-based access control (Admin / User)
- User management for administrators

### 📧 **Automated Email Notifications**

- Send reminders for due rentals
- Notify about overdue books
- Configurable SMTP settings

### 🗄️ **Multi-Database Support**

- SQLite for local development
- Microsoft SQL Server for enterprise deployments
- MariaDB/MySQL support
- Easy database configuration via YAML
